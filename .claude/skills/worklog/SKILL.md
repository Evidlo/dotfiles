name: work log skill
description: WORK.md to maintain tasks between sessions and record progress.  Use BEFORE making any edits to WORK.md
---

WORK.md is a file that should live alongside AGENTS.md and is a lightweight way of keeping track of work between sessions.

Each session gets its own heading `# YYYY-MM-DD - [desc]` followed by bullets containing milestones, gotchas or major discoveries.

Entries should be rather concise to avoid using too many tokens, and should avoid things that would be obvious to future sessions without context.

Do not record anything an agent would already know or could infer on its own: general domain or method background, anything derivable from the code, git history, AGENTS.md or the file layout, or the back-and-forth of a discussion. Record only findings, decisions, and gotchas that are not recoverable from those sources. A session that did no work gets a line, not a section.
