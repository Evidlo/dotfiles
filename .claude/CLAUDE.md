# Code Style

In scientific Python, avoid conditionals where possible.  Instead write code that handles multiple conditions simultaneously (e.g. cast numpy array to known type unconditionally)

Avoid narrative comments which are responses to issues from sessions.  Comment necessity should be apparent in their own context.

# Output

Use unicode characters instead of Latex when talking directly to the user.  e.g.  σ₁ instead of $\sigma_1$
